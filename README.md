# Japanese Hobby & Collectibles Market Price Dataset (Weekly CSV)

**価格: $29.99** | [Gumroadで購入](https://atushi5.gumroad.com/l/agyhq) | [Apify Store](https://apify.com/store/actor/kensho-japanese-hobby-price-dataset)

## 何が入っているか

日本の中古市場（アニメフィギュア・ホビーグッズ・Collectibles）の価格データを**週次更新**で提供するCSVデータセット。

- **収集元**: 価格.com、メルカリ、ヤフオク、駿河屋、ラクマ 他
- **更新頻度**: 毎週日曜日（UTC/JST）
- **フォーマット**: UTF-8 CSV（BOM付き、Excel対応）
- **サイズ**: 約700KB/週

## データサンプル

```csv
product_id,product_name,category,price_jpy,condition,seller_rating,sales_count,listed_at,scraped_at
JH000001,龍が如く 真島吾朗 フィギュア,アニメグッズ,3200,中古,4.5,12,2026-10-04,2026-10-05
JH000002,ポケモンカード ユニオニV SR,カードゲーム,8500,中古,4.8,34,2026-10-04,2026-10-05
```
